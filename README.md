# Часы Первого канала 2000–2011

Веб-реализация эфирных часов Первого канала периода 2000–2011 годов, синхронизированная с локальным системным временем устройства.

Проект создан с использованием искусственного интеллекта — ИИ-ассистента OpenAI Codex, участвовавшего в разработке, тестировании и подготовке документации.

## Возможности

- Работающие часы с 60-секундным анимированным фоном.
- Дневная и ночная музыкальные подложки, Opus → WAV fallback.
- Адаптивное качество видео и явный выбор профиля.
- Восстановление синхронизации после паузы, сна и изменения системного времени.
- Работа в браузере, OBS Browser Source и на GitHub Pages.

## Запуск

Требуется Node.js 20 или новее. Установка npm-пакетов не нужна.

```sh
npm start
```

Открыть [localhost:4173](http://localhost:4173/). Для другого порта: `PORT=8080 npm start`.

Сервер отдаёт только `public/`, поддерживает HTTP Range и локальный путь `/channel-one-clock/`. Для размещения достаточно любого статического HTTP-хостинга; открытие HTML через `file://` не поддерживается.

## Параметры

| Параметр | Значения | По умолчанию |
|---|---|---|
| `audio` | `day`, `night` | `day` |
| `quality` | `auto`, `high`, `medium`, `low` | `auto` |
| `debug` | `1` включает диагностику | выключена |

Примеры: `?audio=night`, `?quality=high`, `?audio=night&quality=low&debug=1`. Неизвестные значения используют настройки по умолчанию. Автоматического переключения дневной и ночной музыки нет.

Видео: high — **1440×1080**, medium — **960×720**, low — **640×480**; все профили имеют 50 fps и минутный цикл.

В режиме auto физическая ширина композиции (CSS-ширина × DPR) до 640 px выбирает low, до 960 px — medium, выше — high. Доступные сетевые подсказки saveData/2g выбирают low, 3g ограничивает качество medium. Профиль выбирается при загрузке; resize его не переключает. При ошибке видео пробуется следующий меньший поддерживаемый профиль.

Звук загружается последовательно: Opus, затем WAV при отсутствии поддержки или ошибке загрузки/декодирования. В браузере звук может ждать первого нажатия, касания или клавиши; после активации он запускается в текущей фазе.

## OBS

Добавить **Browser Source**, установить размер **1440×1080** и URL `http://localhost:4173/?quality=high&audio=day`. Для ночной подложки использовать `audio=night`. Частота кадров — 50 fps.

Время и часовой пояс берутся с устройства, на котором работает OBS. Запуск звука зависит от конфигурации Browser Source и политики autoplay.

## GitHub Pages

В Settings → Pages выбрать **GitHub Actions**. Workflow `.github/workflows/pages.yml` запускается при push в `main` и вручную через workflow_dispatch: проверяет тесты, копирует `public/` в `.pages/` и публикует статический артефакт официальными Pages actions.

Адрес project site: `https://USERNAME.github.io/REPOSITORY/`. Пути к ресурсам относительные; размещение в подкаталоге поддерживается. Все готовые медиа входят в репозиторий.

## Техническая реализация

Static HTML/CSS/JavaScript без backend и внешних библиотек. H.264-видео воспроизводится через MediaSource с заранее подготовленным продолжением минутного цикла; при отсутствии поддержки или ошибке используется нативный video loop. Canvas **1440×1080** для стрелок, Web Audio для музыкальной подложки. Состояния и фаза рассчитываются от `Date.now()`; таймер только запускает очередную проверку. Композиция сохраняет пропорции 4:3.

Проверки:

```sh
npm test
npm run build:pages
```

Для проверки статической сборки:

```sh
STATIC_ROOT=.pages PORT=4175 npm start
# В другом терминале:
npm run check:static -- http://localhost:4175/channel-one-clock/
```
